# Nova Forma Designs

This is the official repository for **Nova Forma Designs**, a freelance digital design and development venture specializing in tailoring digital experiences for small businesses and personal brands.

## Project Origin
This project began as a high-fidelity mockup designed in **Figma** and was subsequently adapted and developed using **Google's new Anti-Gravity IDE**, leveraging advanced AI-assisted coding capabilities to bring the vision to life.

## Business Overview
Nova Forma Designs is the operating name for my freelance digital design and development services. I work as a sole trader, providing personalized, high-quality digital solutions for small businesses and personal brands. This venture stems from my qualifications in **UI Design** and **Full Stack Web Development**, which drove me to establish my own independent practice.

The approach is built around a personalized, "tailored" delivery model focused on creating clean, modern, and high-converting websites.

## Key Features

### 1. Hero Section
- **Visuals**: Custom illustrations representing the "tailoring" and "strategy" aspects of the business.
- **Animation**: Smooth entry animations using Framer Motion.
- **Call to Action**: Clear pathways to start a project or view services.

### 2. About Section
- **Personal Touch**: Introduces the freelancer behind the brand.
- **Value Proposition**: Emphasizes the "tailored" approach vs. generic templates.
- **Highlights**: Client-focused approach, modern design principles, clean code, responsive & accessible.

### 3. My Work
- **Academic Work**: Showcase of the portfolio site built during qualifications.
- **Real-World Project**: Live client work for Penmaen & Nicholaston Village Hall.

### 4. Services
- **Offerings**:
    - Web Design
    - Responsive Development
    - Custom Solutions
    - Brand Identity
- **Interactive Cards**: Hover effects to engage users and highlight specific services.

### 5. Contact Form
- **Direct Communication**: Simple form to capture lead details.
- **Email Integration**: Form submission posts to Formspree for direct delivery.

## Tech Stack
- **Framework**: React (Vite)
- **Language**: TypeScript
- **Styling**: Tailwind CSS & Custom CSS
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Deployment**: Vercel / GitHub Pages

## Local Development
1.  Clone the repository.
2.  Run `npm install` to install dependencies.
3.  Run `npm run dev` to start the local development server.
